🧹 객실 청소 인증 텍스트 만들기

사진을 붙여넣고 객실 상태를 선택하면 청소·인스펙 공유용 텍스트가 자동으로 만들어집니다.
인스펙객실현황에 올리기
이 구역에는 인스펙 완료 객실 사진만 붙여넣기 · 인/아웃=파란색+빨간글씨+* · 체크아웃=파란색 · 뒤에 체크인=살구색+* · 공실=흰색 · 연박=연두색
뒤에 체크인 있는 방이나 공실을 누르면 공실 1차 / 2차 / 3차를 추가로 선택할 수 있습니다.
📷 인스펙 사진 붙여넣기 이 박스를 클릭한 뒤 Ctrl+V 하거나 사진을 선택하세요.
공실 인스펙 단계 선택
선택 0/13
실시간 완성 텍스트 — 항상 직접 수정 가능
예: 401호가 뒤에 체크인이 있고 공실1차라면 401*(공실1차)로 표시됩니다.
객실정비방에 올리기
이 구역에는 호실·더/베/완용 사진만 붙여넣기 · 일반 호실 / 연박 / 공실을 각각 선택합니다.
만실이라 공실이 없는 날은 공실없음 버튼을 누르면 복사 텍스트에 공실0으로 표시됩니다. 아래에서 실제 투숙 인원과 추가 침구를 입력하면 맨 아래 <인원추가 세팅>에 자동 반영됩니다.
📷 호실·더/베/완 사진 붙여넣기 이 박스를 클릭한 뒤 Ctrl+V 하거나 사진을 선택하세요.
🛏️ 인원추가 · 침구 세팅
일일시트의 실제 입실 인원을 입력하세요. 기준인원을 초과한 객실만 카톡 문구에 표시됩니다. 침구는 유료·서비스 구분 없이 추가 수량을 입력하세요. 침구만 추가된 객실도 표시됩니다. 빈칸은 미확인으로 처리합니다.
